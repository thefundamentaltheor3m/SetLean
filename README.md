# Graduate-Level Set Theory in Lean

This project is by some of the students of Carnegie Mellon University's graduate-level set theory course, 21-601, taught by [https://www.math.cmu.edu/~eschimme/](Ernest Schimmerling) in Fall 2026. The objective of this project is twofold: to improve our understanding of the course content by formalising it in Lean and upstreaming our work to Matlhib to develop its [https://github.com/leanprover-community/mathlib4/tree/master/Mathlib/SetTheory](set theory library).
